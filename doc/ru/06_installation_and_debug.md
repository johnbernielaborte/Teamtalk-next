# 06. Установка и отладка плагинов

После сборки `.jar` плагина его можно установить и протестировать на устройстве или в эмуляторе.

---

## 📲 Способы установки

### Способ 1: Через графический интерфейс приложения (Рекомендуемый)
1. Откройте **TeamTalk Next**.
2. Откройте главное меню (три точки в правом верхнем углу) и выберите **«Плагины»**.
3. Внизу экрана нажмите кнопку **«Установить плагин»**.
4. В системном проводнике выберите ваш скомпилированный `.jar` или `.dex` файл.
5. Приложение скопирует файл во внутреннее хранилище, проверит манифест `plugin.json`, создаст `DexClassLoader` и активирует плагин.
6. Всплывающее уведомление подтвердит успешную установку:  
   *«Плагин "Имя плагина" успешно установлен»*.

### Способ 2: Прямое копирование в папку на накопителе
1. Скопируйте `.jar` файл плагина в директорию внешнего хранилища:  
   `/sdcard/Android/data/org.nekit.ttproplus/files/plugins/`
   *(Путь можно скопировать в буфер обмена одним нажатием на верхнюю плашку в экране плагинов)*.
2. Откройте экран «Плагины» и нажмите иконку **«Перезагрузить»** (круговые стрелки) на панели действий.
3. Менеджер плагинов просканирует папку и загрузит новый файл.

## 🔍 Отладка и просмотр логов

Все логи плагинов выводятся через `PluginLogger` со специальным тегом:  
`TTPlugin[<ИмяПлагина>]`

Для просмотра логов в реальном времени используйте утилиту `adb`:

```bash
# Фильтрация только по логам плагинов
adb logcat -s "PluginManager" "TTPlugin*"

# Просмотр подробных ошибок
adb logcat *:E | grep -i "plugin"
```

### Диагностика частых ошибок:
* **`No plugin.json or valid manifest found`**: убедитесь, что при упаковке ZIP архив `plugin.json` положен в корень архива рядом с `classes.dex`.
* **`Class ... does not implement Plugin`**: проверьте, что класс реализует `org.nekit.ttproplus.plugin.Plugin` или наследует `BasePlugin`.
* **`onLoad failed` / `onEnable failed`**: ошибка внутри метода плагина; подробный стектрейс выводится в логкат и отображается красным текстом в карточке плагина в интерфейсе.
