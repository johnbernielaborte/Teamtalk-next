# Документация системы плагинов TeamTalk Next (RU)

Система плагинов **TeamTalk Next** позволяет сторонним разработчикам создавать динамически загружаемые модули на Java/Kotlin, расширяющие функциональность мобильного клиента без модификации основного исходного кода приложения.

---

## 📚 Разделы документации

1. [**01. Архитектура и принципы работы**](01_architecture.md)
   * Механизм загрузки `DexClassLoader` в среде Android ART/Dalvik.
   * Жизненный цикл плагина (`onLoad`, `onEnable`, `onDisable`, `onUnload`).
   * Изоляция хранилища данных и настройки.
   * Отказоустойчивость: защита приложения от сбоев в плагинах.

2. [**02. Быстрый старт**](02_quickstart.md)
   * Структура проекта плагина.
   * Написание первого плагина (класс `EchoBotPlugin`).
   * Манифест `plugin.json` — назначение полей и структура.

3. [**03. Справочник API**](03_api_reference.md)
   * Методы интерфейса `PluginContext` (отправка сообщений, управление каналами, доступ к SDK).
   * События `PluginEventListener` (сеть, сообщения, каналы, участники, звук).
   * Логирование через `PluginLogger`.
   * Асинхронные задачи и планировщик таймеров.

4. [**04. Слэш-команды и интерфейс**](04_commands_and_ui.md)
   * Создание и регистрация команд чата (начинающихся с `/`).
   * Обработчик `PluginCommandHandler` и отправитель `PluginCommandSender`.
   * Пользовательские действия и кнопки `PluginAction` в интерфейсе.

5. [**05. Сборка и упаковка плагина**](05_building_and_packaging.md)
   * Компиляция Java исходников в `.class` файлы (`javac`).
   * Трансляция байткода в Android DEX (`d8` из Android SDK Build-Tools).
   * Упаковка в итоговый `.jar` или `.dex` файл.

6. [**06. Установка и отладка**](06_installation_and_debug.md)
   * Установка через встроенный графический интерфейс «Управление плагинами».
   * Ручная установка в системную папку на устройстве.
   * Отладка и просмотр логов через `adb logcat`.
